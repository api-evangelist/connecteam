# Connecteam Documentation

> Connecteam is an non-desk workforce management app designed to help businesses communicate, increase collaboration and streamline work with a set of operational, communication, and HR tools. Connecteam's API is your gateway to unlocking the full potential of our comprehensive workforce management platform. Whether you're a small business or an enterprise, our API empowers you to tailor Connecteam to your unique needs and seamlessly integrate it with your existing systems and processes.

- [Shifts Created Event](https://developer.connecteam.com/reference/shifts_created_eventshifts_created_post.md): Receive real-time data updates on shifts creation at your specified URL.   **V1** (default): one event per individual user assignment.   **V2**: aggregates all user assignments of the same shift into a single event, with a combined list of assigned user IDs and a base shift ID. Adding a new user to an existing shift triggers a **shift.updated** event instead. Contact us to enable V2 for your account.   Find more details about event types and payload examples in the Guides -> Webhooks section for a deeper understanding.
- [Shifts Deleted Event](https://developer.connecteam.com/reference/shifts_deleted_eventshifts_deleted_post.md): Receive real-time data updates on shifts deletion at your specified URL.   **V1** (default): one event per individual user assignment.   **V2**: uses base shift IDs and only fires when the entire shift is removed. Unassigning a single user from a multi-user shift triggers a **shift.updated** event instead. Contact us to enable V2 for your account.   Find more details about event types and payload examples in the Guides -> Webhooks section for a deeper understanding.
- [Shifts Updated Event](https://developer.connecteam.com/reference/shifts_updated_eventshifts_updated_post.md): Receive real-time data updates on shifts updates at your specified URL.   **V1** (default): one event per individual user assignment.   **V2**: aggregates all user assignments of the same shift into a single event, with a combined list of assigned user IDs and a base shift ID.
